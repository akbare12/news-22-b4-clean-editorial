A clean white editorial front page summing up Sunday 22 November 2026 in one
image: three big heroes (two tankers hit by mines near the Strait of Hormuz,
COP31 collapses with no deal in Antalya, Democrats win 258 House seats),
a number strip, a pinned world map with a UTC timeline, and 26 more stories
in brief — 29 stories in all, every one first reported on 22 Nov, with a
verification legend (REPORTED / CLAIM / DENIAL / ONGOING) and a date-check
footer naming what was excluded.

`main.py` (Python 3.13, stdlib only) copies `entry.png` to the output
directory and verifies the copy byte-for-byte (sha256 + size).
